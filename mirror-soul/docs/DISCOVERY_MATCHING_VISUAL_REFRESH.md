# 발견·매칭 화면 디자인 개편

- 기준: `origin/dev`의 `75da6da` (PR #198 병합)
- 작업 브랜치: `codex/discovery-matching-visual-refresh`
- 범위: RN 화면·공용 표현 컴포넌트·회귀 테스트. 백엔드·AI·인프라 수정 없음.

## 화면 구성

### 발견

- 남은 시간·탐색 지역을 하나의 작은 설정 패널로 묶는다.
- 추천 카드 한 장에 집중하도록 뒤에 겹쳐 보이던 장식 카드를 제거한다.
- 4:3 사진 아래에 이름·나이 → 지역·직업 → 소개 → 성격 태그 → 버튼을 배치한다.
- `프로필 보기`와 `트윈과 통화`의 누르는 영역을 분리한다. 사진 터치는 크게 보기로 연결하되 사진이 없거나 다운로드에 실패하면 상세 프로필을 연다.
- 긴 소개는 펼치고 접을 수 있다. `밀어서 둘러보기` 안내와 번호 표시는 제거하고, 이동이 불편한 사용자와 화면 읽기 기능을 위해 카드 아래에 48px 보조 화살표를 유지한다. 왼쪽으로 밀면 다음, 오른쪽으로 밀면 이전이며 첫 카드에서는 오른쪽 이동을 막는다.
- 카드 회전은 제거하고 수평 이동으로만 넘긴다. 실제 카드 폭에 맞는 거리 또는 24px 이상 같은 방향으로 움직인 빠른 제스처만 인정하며, 짧은 손짓·방향 반전·취소는 제자리로 돌아온다. 전환 중 중복 제스처를 차단하고 기기의 모션 줄이기 설정을 따른다.
- 추천 카드의 점수·직업·기본 아바타·이동·통화 아이콘은 [Phosphor duotone 공식 SVG](https://github.com/phosphor-icons/core)를 로컬 경로로 렌더링한다. 원본과 MIT 라이선스는 `assets/icons/phosphor`에 동봉한다. 사진 확대 아이콘도 가입 미리보기와 실제 카드에서 공유한다. 패키지나 네이티브 모듈을 추가하지 않는다.
- 직업은 퍼플 계열 서류가방 배지, 추천 점수·MBTI는 시안 계열, 성격 태그는 중립적인 테두리로 정보의 종류를 구분한다. 서류 제출 여부는 승인 완료를 의미하지 않으므로 공개 카드·상세에서 제출 표시는 숨긴다.
- 추천 노출 설정은 카드 뒤에 별도로 둔다. 추천 노출을 끄더라도 상대 둘러보기는 허용한다.

### 통화 시작 확인 시트

- 기존 420px 고정 높이를 없애고 실제 본문·하단 버튼 측정 높이에 맞춰 표시한다. 화면 높이에서 상단 안전 영역과 여백을 제외한 범위를 넘지 않는다.
- 본문은 세로 스크롤을 허용하고 시작 버튼은 일반 화면에서 별도 하단 영역에 둔다. 가용 높이 360px 미만 또는 글자 배율 1.8 초과에서는 버튼도 본문 끝으로 옮겨 긴 버튼 문구가 내용을 덮지 않도록 한다.
- 좌우 안전 영역, 하단 홈 표시줄·Android 탐색 영역을 고려한다. 본문 간격과 시간 카드 여백은 12px, 좌우 여백은 기본 16px이며 긴 닉네임·안내 문구는 자연스럽게 줄바꿈한다.
- 본문 스크롤과 닫기 제스처가 충돌하지 않도록 공용 BottomSheet의 기존 `dragFromHandleOnly` 옵션을 사용한다. 명시적인 닫기 버튼도 제공한다.
- 시간 차감·자동 종료 안내는 한 문장으로 합친다. 잔액 새 조회가 끝나기 전이나 조회 실패 시 시작을 막고, 실패 재시도·0초 충전·개발용 미리보기 분기를 유지한다. 시작과 충전 전환 연타는 동기 락으로 막는다.

### 매칭

- 받은 신청·메시지 탭은 같은 높이의 분할 선택 영역으로 표현한다. 아이콘·제목·개수 배지를 한 그룹으로 중앙 정렬하고 Android 글꼴의 추가 위아래 패딩을 제거한다. 개수 배지는 제목과 따로 줄바꿈되지 않도록 하며, 글자 배율 1.3 초과에서 장식 아이콘을 숨기고 1.5 초과에서는 제목 아래에 개수를 배치한다. 터치 높이는 최소 48px이며 글자 확대 시 필요한 만큼 커진다.
- 신청과 메시지 카드는 16px 안쪽 여백, 16px 모서리, 12px 내부 간격을 중심으로 정리한다.
- 이름은 16~18px, 본문은 14~15px를 사용하고, 지나치게 굵은 글씨·큰 아바타·반복 장식을 줄인다.
- 수락·통화는 연한 하늘색 채움, 상세 보기는 더 연한 채움과 테두리로 구분한다. 선택 탭과 메시지 필터에도 같은 하늘색을 사용한다. 처리 중 중복 실행 방지는 유지한다.
- 탭·메시지 필터와 첫 목록 사이 여백은 4px로 정리한다. 탭 영역과 필터는 내용에 따라 높이가 늘어나도록 유지한다.
- 화면 진입·포커스·앱 복귀·캐시 갱신에 따른 자동 재조회는 목록의 native 새로고침 표시를 활성화하지 않는다. 사용자가 직접 아래로 당길 때만 그 표시를 켜고 완료 후 해제한다. 헤더의 새로고침은 기존 위치의 작은 스피너로 표시한다. 이로써 자동 갱신 중 전체 목록이 아래로 밀리지 않도록 한다.
- 매칭의 실제 사용 화면(탭·새로고침·받은 신청·메시지 목록·빈 상태·노출 안내·신청 상세)은 같은 Phosphor duotone 아이콘을 사용한다. 메시지 빈 화면에는 메시지 아이콘을, 조회 실패에는 연결 오류 아이콘을 사용한다. 빈 상태의 아이콘 아래 중복 여백도 제거한다.
- 추천 노출 설정은 목록 끝에 별도로 둔다.

### 추천 프로필 상세 / 내 공개 미리보기

- 사진은 가입·사진 수정 미리보기의 4:5, 중앙 cover 크롭, 16px 모서리, 하단 그라디언트와 이름 영역을 공유한다. 이름은 사진 위, 나이·지역·직업·소개는 아래에 표시한다. 추천 카드도 미리보기와 같은 4:3·오른쪽 아래 사진 확대 아이콘, 원형 사진도 같은 중앙 크롭을 사용한다. 미리보기의 안내 문구는 미리보기에서만 보인다.
- 닫기는 상단 독립 영역에 둔다. 소개·목소리 미리듣기·트윈 성향·MBTI 밸런스를 같은 글꼴 계층으로 정리한다.
- 통화 버튼은 보통 화면 아래의 별도 영역에 둔다. 높이 500 미만 또는 글자 배율 1.5 초과에서는 스크롤 내용 안으로 옮겨 본문이 가려지는 것을 막는다.
- 태블릿에서는 공용 `useLayout` 너비 제한과 사진 높이 제한을 적용한다. 사진·추천 카드 최대 너비는 사진 편집기와 같은 440px이다. 사진 편집기는 조작 버튼과 안내가 있는 가용 공간에 맞춰 작아질 수 있으므로, 모든 화면의 픽셀 크기를 강제로 같게 하지 않고 사진 비율과 구도를 일치시킨다.
- MBTI 유형(INFP 등)은 사진 아래에서 제거하고 성향 밸런스 제목 옆에 배치한다. 작은 폭·큰 글자에서는 제목과 배지가 자연스럽게 줄바꿈하며, 서버 성향 수치가 없으면 유형만 표시한다.
- 상세에서 통화 확인과 충전은 기존 Modal 내부에 시트를 표시한다. 취소·Android 뒤로 가기 시 프로필과 스크롤 위치를 유지하고, 확인 후 실제 통화 시작 시에만 화면을 전환한다. 중첩 native Modal을 만들지 않으며 시트 동안 배경의 화면 읽기 접근을 숨긴다. 목소리 미리듣기는 시트 열기·상세 닫기 시 일시정지하고 이미 대기 중인 재생도 시작하지 않는다. 충전 본문은 작은 화면·큰 글자에서도 스크롤할 수 있고 옵션 높이를 고정하지 않는다.
- MBTI 밸런스는 가로 그래프 대신 네 성향을 2×2 요약 카드로 표시한다. 에너지 방향·정보 이해·결정 방식·생활 방식마다 우세한 성향과 비율을 크게, 반대 성향과 비율을 보조 정보로 표시한다. 기존 시안·퍼플로 성향 글자를 강조하고 배경은 중립적인 카드 색상을 사용한다. 50:50은 `균형`과 양쪽 이름·비율을 표시한다. 실제 가용 폭 272px 미만이나 글자 배율 1.3 초과에서는 한 열로 배치하고 글자·카드 높이를 고정하거나 잘라내지 않는다. 높은 점수는 기존 API의 I/N/F/P 방향을 유지한다. 비정상 값은 제외하고 범위 밖 값은 0~100으로 제한하며 반올림 후 양쪽 합은 100%이다. 축별 점수를 조합해 새로운 MBTI 유형을 만들지 않는다. 상대 상세와 내 공개 미리보기는 이 공용 컴포넌트를 공유한다.
- 본문 간격과 여백은 16px, 음성 카드 여백은 12px로 줄이고 본문·MBTI 문구의 높이를 고정하지 않는다.
- 내 공개 미리보기는 같은 레이아웃을 공유하되 상대 추천 API를 호출하거나 통화 버튼을 표시하지 않는다.

## 색상·글자·반응형 원칙

- 발견·매칭·기록·성장·프로필은 공용 `MainTabHeader`로 왼쪽 제목 아래에 짧은 탭 안내를 표시한다. 색 막대는 없다. 제목은 24px Medium, 안내는 14px 보조 색상·21px 줄 높이이며 줄 수나 높이를 고정하지 않는다. 상단 버튼의 기존 동작은 유지한다.
- 제목·사용자 이름은 [네이버 나눔스퀘어라운드 공식 배포](https://hangeul.naver.com/font)의 Regular·Bold를 사용한다. 실제 한글·영문 글꼴 형태를 부드러운 것으로 바꾸며, 사진 위 이름은 가입 미리보기와 일치하도록 기존 Inter를 공유한다.
- 본문에는 [SUITE 공식 배포](https://github.com/sun-typeface/SUITE)의 Regular·Medium·SemiBold를 RN assets에 동봉했다. 발견·매칭의 `BrowseText` 본문에 적용한다. 한글과 영문을 같은 글꼴로 표현하고, 굵기는 실제 정적 글꼴 파일로 구분해 기기별 합성 굵기에 의존하지 않는다. 시스템 글자 확대는 유지한다.
- 글꼴은 기존 `expo-font`로 로컬 파일에서 로드한다. 초기 화면을 보여주기 전에 세션·글꼴 준비를 기다리며, 로드 실패 시 기존 글꼴로 앱을 실행한다. 네이티브 설정·패키지는 변경하지 않는다.
- 글꼴별 라이선스는 `assets/fonts/SUITE-LICENSE.txt`와 `NanumSquareRound-LICENSE.txt`에 동봉한다. SUITE는 공식 Git blob hash 일치를 확인했고 나눔스퀘어라운드는 네이버 공식 CDN 파일이다. 실제 화면의 한글·영문·숫자 표본이 포함되었는지 확인했다. 추가한 나눔 글꼴 두 개는 합계 약 2MiB다.
- 기존 밝은/어두운 테마의 배경·텍스트는 유지하고 기록·성장에서 사용하는 시안·퍼플을 재사용한다. 선택 탭은 연한 하늘색, 직업 태그·아바타는 옅은 퍼플, 작은 시간 아이콘은 시안이며 넓은 코발트 채움을 없앤다. 밝은 테마의 작은 글씨는 같은 색상을 어둡게 조정해 흰 바탕 대비 퍼플 8.07:1, 시안 7.13:1이다. 주요 버튼은 기존 시안에 흰색을 섞은 `#d1f7fd`이며 글씨는 `#003942`로 대비 11.08:1을 확보한다. 전역 테마 색상은 수정하지 않는다.
- 사진 이외의 정보는 고정 높이 대신 내용에 따라 커지도록 배치한다. 버튼 최소 터치 높이는 48px이다.
- iOS는 한글 단어 줄바꿈, Android는 고품질 줄바꿈 옵션을 사용한다. 시스템 글자 확대를 허용한다.
- 카드의 실제 측정 너비가 300 미만이거나 글자 배율이 1.3 초과면 두 개의 행동 버튼을 세로로 배치한다.
- 가로 화면의 좌우 안전 영역과 하단 탭 바 높이를 고려한다. 스와이프 거리 판정에는 화면 전체 너비 대신 실제 카드 너비를 사용한다.

## API 확인

스냅샷 `.claude/artifacts/backend-schema.json`·`analysis-report.md`를 먼저 읽고, 이후 추가된 홈 기능은 실제 Controller·DTO·Service로 재확인했다.

| 기능 | 사용 계약 | 유지하는 의미 |
| --- | --- | --- |
| 추천 목록 | `GET /home/recommend`, `RecommendResDTO.RecommendationSliceDTO` | 페이지·hasNext·추천 점수·사진·직업·소개·성격 태그 |
| 추천 상세 | `GET /home/recommendations/{uuid}` | 상세 응답을 정본으로 사용. 상세에서 null인 사진 등을 목록의 이전 값으로 되살리지 않음 |
| 다음 후보 | `POST /home/recommendations/{uuid}/swipe` | 다음에 PASS 기록. 이전 이동은 로컬 위치만 변경 |
| 내 추천 노출 | `GET/PATCH /match/status` | 노출 설정과 상대 둘러보기를 구분 |
| 받은 신청 | 기존 meeting 조회·accept·reject API | 서버 상태·중복 처리 방지·오류 복구 유지 |
| 메시지 | 기존 chat 목록·읽지 않은 수·방 이동 | 실제 최신 메시지와 방별 알림 설정 표시 유지 |

`recommendationScore`는 추천 점수이고 상세의 `syncRate`는 트윈 싱크로율이다. 서로 대체하거나 매칭 확률로 표현하지 않는다. `jobCertificationSubmitted`는 S3 object key 존재 여부로만 계산된다. 운영자 승인 상태가 아니므로 공개 화면에서 제출·완료 배지를 표시하지 않는다.

API 요청·응답 타입과 서버 코드는 변경하지 않았다.

### 직업 인증 완료 표시를 위한 백엔드 요청

현재 `User`에는 서류 object key만 있고, `/admin/job-verify`는 실제 승인 처리 없이 null 응답을 반환한다. RN은 승인된 회원을 구분할 수 없다. 현재 추가한 직업 배지는 직업 종류만 표시하며 인증 표시가 아니다.

| 응답 | 요청 필드 | 판정 기준 |
| --- | --- | --- |
| 추천 목록 `/home/recommend` | `jobVerified: boolean` | 운영자 승인 상태가 APPROVED일 때만 true |
| 추천 상세 `/home/recommendations/{target-user-uuid}` | 동일 필드 | 목록과 동일한 서버 판정 |
| 내 공개 프로필 `/my-page/profile` | 동일 필드 | 상대 화면과 내 미리보기의 배지 일치 |

서류 등록 여부와 승인 여부는 별도로 저장·판정해야 한다. 제출, 반려, 미제출은 인증 완료로 표시하지 않고 직업이나 증빙이 바뀌면 기존 승인의 유효성을 서버에서 재판정해야 한다. 서버 구현·배포 후 RN 타입과 실제 응답을 연동하여 `jobVerified === true`인 경우에만 `직업 인증 완료` 배지를 제공한다. 현재 RN에 존재하지 않는 응답 필드를 가정하거나 서류 제출을 승인으로 변환하는 처리는 넣지 않았다.

## 발견 정보와 대화 시간 충전

- 남은 시간·탐색 지역은 기본 높이 56px의 가로 바 하나로 표시한다. 왼쪽의 시안색 시간·더하기는 기존 충전 창, 오른쪽의 지역명·화살표는 기존 지역 설정 화면으로 연결한다. Feather 선형 시계·위치 아이콘과 앱 색상을 유지하고 중복 제목·배경 장식은 줄인다. 지역은 주변 동을 포함하면 ‘성수동 주변’처럼 요약하고 접근성 이름에는 실제 추가 동 개수를 제공한다. 실측 너비가 부족하거나 글자 배율이 크면 같은 바 안에서 두 줄로 배치한다. 지역은 말줄임/줄바꿈에 대응하고 전체 이름을 접근성에 유지한다.
- 시간은 기존 `GET /my-page/buy-time`, 지역은 기존 `GET /home` 응답을 그대로 사용한다. 로딩 중인 값을 0초·전체 지역으로 표시하지 않고, 조회 실패 시 해당 영역만 재시도한다. 두 버튼의 터치 높이는 각각 최소 48px이다. 설정 바와 추천 섹션의 관련 테스트 14개 및 변경 파일 ESLint/타입 확인을 통과했다.
- 공식 Phosphor duotone 아이콘은 충전 창의 선택·약관에 적용했다. 에셋과 MIT 라이선스는 앱에 포함하며 별도 네이티브 의존성은 추가하지 않았다.
- 충전 창은 시간 선택 → 명시적 확인으로 변경했다. 선택 자체로 POST하지 않으며 확인 연속 입력을 동기 락으로 막는다. 실패하면 선택을 유지하고 잔액을 재조회한다.
- 실제 서버가 결제 없이 시간을 추가하므로 가격을 예시로 표시하고 테스트 충전으로 안내한다. 취소선은 30분 예시 상품 대비 비교 가격이며, 2시간 4,700원·약 24%, 10시간 39,000원·약 40% 절약으로 계산한다.
- 12개 조항의 충전 약관 초안과 공식 법령 링크를 같은 창 안에서 읽는다. 사업자·고객센터·결제 경로·유효기간·환불 산식 등은 미정으로 명시한다.
- 약관에서 돌아와도 선택은 유지한다. 가로 화면·큰 글자는 확인 버튼을 스크롤 안에 배치한다. 이전 요청이 완료되어도 재열린 충전 창을 닫지 않는다.
- 확정할 정책과 정식 결제의 서버 요구사항은 `TIME_REFILL_DRAFT_AND_PAYMENT_HANDOFF.md`에 정리했다.

받은 신청 탭과 빈 상태는 하트 대신 Phosphor `user-plus`(사람 +) 아이콘으로 통일했다. 신청 카드의 AI 대화 공감도는 별빛 아이콘으로 구분한다. 기존 아이콘 크기와 버튼 배치는 유지한다.

## 통화 기록 상세의 상단 행동

전화 버튼은 기록의 상대 UUID로 기존 AI 트윈 통화 확인·잔액 조회·충전·실제 통화 화면에 연결했다. 더보기는 버튼 좌표에 붙는 팝오버이며 통화 정보·새로고침·안내·사용자 상세·신고 메일 작성·실제 차단을 제공한다. 두 상단 버튼의 크기·선형 아이콘을 맞추고 긴 이름은 말줄임 처리한다. 수정 보호, 늦은 이동/조회 취소, 단일 native 통화 Modal, Android 뒤로 가기, 안전 영역과 차단 후 목록 일관성을 검증했다. 전체 프로필의 추천 노출 이력 제약 및 정식 신고 접수 API의 서버 협의 내용은 `HISTORY_DETAIL_ACTIONS.md`에 정리했다.

## 검증

- Jest 전체 90개 묶음·551개 테스트 통과. 회귀 테스트는 버튼별 동작, 사진 실패·늦은 콜백, 삭제된 사진의 정본 반영, 작은 화면·큰 글자의 통화 접근, 스와이프 방향·취소·첫 카드·실측 너비, 짧은 빠른 손짓·방향 반전·중복 스와이프 방지, 상세 통화 취소·0초 충전·Android 뒤로 가기 후 스크롤 유지와 단일 native Modal, 통화 시트 중 재생 중단·대기 중 재생 차단, 실제 글꼴 선택과 로드 실패 대체, 준비된 사진 미리보기와 실제 상세의 공유 구도, MBTI 축 방향·우세 성향 강조·균형·비정상 값과 실측 너비·큰 글자의 카드 배치를 확인한다. 통화 시트는 최신 잔액 확인 전 시작 차단, 오류 시 캐시 잔액으로 시작 차단, 0초 충전과 중복 전환 방지, 측정 높이 제한, 가로 화면·큰 글자에서의 버튼 접근, 닫기와 본문 스크롤 분리도 확인한다. 매칭 자동 갱신 시 native 새로고침 표시 비활성화·수동 갱신 유지, 직업 서류 제출을 승인 완료로 표시하지 않는 공개 카드·상세 처리도 확인한다.
