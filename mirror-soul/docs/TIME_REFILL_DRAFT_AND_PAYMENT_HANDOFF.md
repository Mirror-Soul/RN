# 대화 시간 충전 UI · 예시 가격 · 약관 초안

검토 기준일: 2026-10-05. RN 변경만 포함하며 백엔드·AI·인프라는 변경하지 않았다.

## 현재 구현과 표시

- `GET /my-page/buy-time`으로 남은 시간을 읽고, 기존 `POST /my-page/buy-time`에 `buyTime`(초)을 전달한다.
- 실제 `ProfileService.buyTime()`은 사용자의 잔액에 요청 시간을 더하고 최신 잔액을 반환한다. 가격·결제 검증·영수증·주문·환불·만료 처리는 이 메서드에 없다.
- 따라서 현재 UI는 **결제 없는 테스트 충전**으로 표시한다. App Store 결제 안내와 약관의 무동작 로그를 제거했다.
- 시간 선택은 API를 호출하지 않는다. 선택 후 명시적인 확인 버튼에서만 기존 시간 추가 API를 호출한다. 연속 확인은 동기 락으로 막고 자동 재요청하지 않는다.
- 서버 실패 시 선택은 유지하고 잔액을 재조회한다. 단, 서버는 요청을 완료했지만 응답이 유실된 경우의 중복 재시도까지 RN 락으로 보장할 수는 없다. 실제 결제에는 서버의 주문·멱등 처리가 필요하다.
- 요청 중 닫고 다시 연 경우, 이전 요청 결과로 새 창을 닫지 않는다. 업로드·콜 등 다른 기능의 API는 변경하지 않았다.
- 작은 화면·가로 화면·큰 글자는 자연스러운 줄바꿈과 스크롤을 허용한다. 화면 높이가 400 미만 또는 글자 배율 1.6 초과면 확인 버튼도 스크롤 안에 넣는다. 일반 화면은 버튼을 하단에 유지한다.
- 약관은 현재 바텀시트 안에서 읽는다. 약관에서 돌아와도 선택이 유지되며 별도 native Modal이나 라우트 이동을 만들지 않는다.

## 가격 예시와 취소선의 의미

| 시간 | 비교 가격 | 예시 가격 | 절약 표시 |
| --- | ---: | ---: | ---: |
| 30분 | — | 4,900원 | — |
| 2시간 | 19,600원 | 14,900원 | 4,700원 · 약 24% |
| 10시간 | 98,000원 | 59,000원 | 39,000원 · 약 40% |

비교 가격은 **같은 시간을 30분 예시 상품으로 채울 때의 가격**이다. 과거 판매가·정가·실제 할인 행사라는 뜻이 아니다. `timeRefillOptions.ts`의 숫자 가격과 초 단위 값을 정본으로 계산한다. 판매 실적을 확인하지 않았으므로 '인기' 배지는 '추천'으로 교체했다.

## 약관 초안의 상태

앱 안에서 읽는 12개 조항과 공식 링크는 `src/features/profile/constants/timeRefillTerms.ts`에 있다. **시행 중인 확정 약관이나 법률 검토 완료 문안이 아니다.** 사업자 정보, 고객센터, 결제 경로, 유효기간, 차감 기준, 부분 사용 환불 산식·절차, 장애·운영 종료 보상은 미정으로 표시했다. 지금 유료 약관 동의나 결제를 받지 않는다.

실제 구현과 확정된 운영 정책에 맞춘 법률 검토 후 시행일을 정해야 한다. 디지털콘텐츠 제공 개시만으로 모든 청약철회가 사라진다고 표현하지 않으며, 가분적인 미제공 부분과 법정 고지 요건 등을 고려한다. 테스트 시간과 실제 구매 시간은 향후 서버에서 구분해야 한다.

## 정식 결제를 위한 백엔드·운영 협의

아래는 신규 API 제안이며 현재 응답에 존재한다고 가정하여 RN에 추가하지 않았다.

| 영역 | 서버·운영에서 확정할 것 |
| --- | --- |
| 상품 정본 | `productId`, 제공 초, 통화·금액, 활성 여부, 적용 조건 및 비교 기준, 스토어 상품 식별자. 임의의 RN 가격·초를 그대로 유료 주문으로 신뢰하지 않기 |
| 구매 확인 | 주문 식별자, 서버에서 검증한 결제 결과, 멱등 키·거래 중복 검증, 시간 지급과 주문 상태의 원자성. 스토어 결제 도입 시 서버 알림과 영수증 검증 |
| 잔액·사용 내역 | 유료·무료 시간 구분, 남은 초, 유효기간, 차감·복구 사유, 주문과 연결된 지급 내역. 통화 차감 기준 및 동시 통화 처리 |
| 환불·운영 종료 | 미제공 시간 판정, 부분 사용 환산, 법정 청약철회, 환불 상태·금액·접수 채널, 결제 취소와 시간 회수의 일관성 |
| 약관·사업자 정보 | 사업자 정보·고객센터, 확정 약관 버전·시행일·고지 방식, 정식 판매 전 필요한 동의 및 기록 |
| 개인정보 | 거래 보존 기간과 사진·음성·생체정보 보유 목적을 구분. 법정 보존 데이터의 분리 관리 |

## 실기기 확인

- 발견의 시간·지역을 확인하고 각각 충전 창·지역 선택으로 진입하기.
- 2시간·10시간 비교 금액 확인 → 선택만으로 시간이 변하지 않는지 → 확인 후 잔액 반영.
- 약관 전체 읽기 → 돌아와 선택 유지 → 닫기 → 프로필 상세 스크롤 위치 유지.
- 작은 기기·큰 글자·가로 화면에서 약관 링크, 마지막 상품, 확인 버튼 접근. iOS 홈 표시줄 및 Android 하단 탐색 영역 겹침 확인.
- 서버 실패, 연속 확인, 요청 중 닫기·재열기. 현재 테스트 API이므로 실제 구매·환불 테스트로 간주하지 않기.
