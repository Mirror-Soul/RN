## 로그인 화면 소폭 조정

로고·워드마크 크기와 주요 영역 간격을 줄였다. 이메일·비밀번호 라벨 크기와 입력 영역의 높이를 맞추고 비밀번호 찾기를 입력 영역 아래 오른쪽에 배치했다. 가입 재개 안내를 두 줄로 정리했다.
최소 48pt 보조 버튼 터치 영역, 글자 확대 시 높이 확장, 안전 영역, iOS/Android 키보드 대응은 유지한다.
관련 Jest 2개 묶음·9개 테스트와 수정 파일 ESLint가 통과했다. 실기기 레이아웃 확인은 별도로 필요하다.
