# 성장 탭 UX와 백엔드·AI 연동 점검

2026-10-05. RN·AI 체크아웃과 백엔드 최신 원격 `origin/main` 커밋 `8189275`(PR #194)을 기준으로 분석했다. 백엔드는 fetch 후 `git show`로 읽었으며 체크아웃하거나 파일을 변경하지 않았다. RN만 수정했으며 백엔드·AI·인프라 코드나 submodule 포인터는 변경하지 않았다. 배포 서버 동작을 직접 검증한 결과는 아니다.

## 이번 RN 변경

- 프로필 인증을 **직업 인증**으로 바꿨다. 트윈 준비도 헤드라인 오른쪽의 원래 버튼 위치에 배치하고 제출 여부는 `GET /my-page/profile`의 `jobCertificationSubmitted`에서 읽는다. 로딩·오류·미제출을 구분하며 실제 승인 여부를 추정하지 않는다.
- 실제 사진첩 선택·카메라 촬영·미리보기·첨부 삭제·사진 변경을 연결했다. 교체 선택 취소 시 기존 사진을 유지하며 카메라 권한 거절 시 사진첩/기기 설정 대안을 안내한다. 사진 로딩 오류도 별도로 안내한다.
- 사진 선택 전에 **제출 기능 준비 중**임을 알린다. 현재는 서버 전송/심사 접수 API가 없으므로 제출 버튼이 비활성화된다. 민감한 사진을 S3에만 올리고 접수됐다고 표시하는 방식은 사용하지 않는다. 창 닫기/계정 변경은 선택 상태를 초기화하고 이전 피커 응답을 무시한다. 앱 캐시 파일을 영구 삭제했다고 보장하는 문구는 사용하지 않는다.
- 직업 확인에 불필요한 주민등록번호·주소·급여를 먼저 가리도록 안내한다. 서류는 공개 프로필 사진과 다른 용도이며, 미래의 제출 과정은 담당자 확인과 시간이 필요하다는 점을 설명한다. 현재 승인 마크를 표시하지 않는다.
- 기존 카드의 틴트·둥근 형태를 유지하고 글꼴을 앱의 SUITE/Pretendard로 통일했다. 긴 제목을 말줄임하지 않으며 상태는 제목 오른쪽에 배치한다. 실제 텍스트 영역이 좁거나 접근성 글자가 크면 상태를 별도 줄로 내려 읽을 공간을 확보한다. 가치관 게임은 게임패드 아이콘으로 표시하고, 대기 카드는 `휴식 중`과 `다음 질문 10/6 14:30`으로 중복 안내를 줄였다. 시각은 한국 시간 기준이며 스크린리더 안내와 클릭 후 화면에서 기준을 확인할 수 있다. 대기 시트도 높이를 줄이고 큰 글자에서는 확대하며, 내용은 자연 높이를 유지해 낮은 가로 화면에서도 스크롤할 수 있다. 작은 화면·큰 글자에서는 아이콘 크기를 줄여 텍스트 공간을 확보한다.
- 트윈 시뮬레이션은 내 트윈이 준비됐는지 확인하고, 시작 전 **연결 후 대화 시간 차감**을 알린다. 현재 GET /evolve에서 숫자 syncRate가 나오는 경우는 백엔드의 READY 상태다. 실패/준비 중에는 상태를 다시 확인하며 바로 통화로 이동하지 않는다. 네이티브 Alert 대신 앱 바텀시트와 최신 잔액 조회를 재사용하며, iOS에서는 모달이 닫힌 뒤 통화 화면을 연다. 오래된 계정/화면의 확인창으로 통화를 시작하지 않는다.
- 얼굴 재학습 API가 최신 원격에 추가됐음을 확인해 실제 연동했다. 가입과 성장에서 동일한 FaceCaptureScreen·얼굴/어깨 가이드·20~25초 촬영·직접 등록 흐름을 공유한다. 영상을 face-videos에 업로드한 뒤 성장에서는 POST /evolve/face에 objectKey만 전송한다. 가입은 기존 POST /onboarding/visual 계약을 유지한다. 실패 시 영상과 업로드 키를 유지해 재시도하고, 계정 변경/중복 전송을 차단한다. 성공 안내는 접수이며 AI 학습 완료를 의미하지 않는다.
- 가치관 게임의 12시간 잠금을 AI 분석 중으로 표현하지 않는다. `lockedUntil`의 한국 시간과 답변 진행을 표시하며 마지막 질문 직후 POST의 locked/completed 응답을 바로 반영한다. 전 문항 답변 완료와 AI 분석 완료를 구분한다. 동기 락으로 연속 제출을 막고 질문 제출 실패 시 현재 질문을 유지한다.
- 목소리의 총 N회 학습을 **녹음 제출 N회**로 바꿨다. 전송 중/학습 요청 접수 안내를 구분한다. 성공은 학습 완료가 아니라 접수 완료다. 긴 낭독 문장·자막·큰 글자에서도 스크롤로 종료/후속 버튼에 접근할 수 있도록 고정 폭/높이를 제거했다.
- 준비도는 얼굴·음성·성격·데이터 완성도를 합산한 지표다. 완벽한 트윈, 100% 완성, 매칭 확률 증가를 약속하던 문구를 제거했다.
- 가치관/낭독 문장 캐시는 회원별로 나누고 인증 전 요청하지 않는다. 녹음 전송 단계마다 계정을 확인하고, 이전 계정의 늦은 결과가 새 계정의 캐시 갱신에 영향을 주지 않게 했다.

## 뒤로가기·목소리 화면 후속 개선

- 성장 화면의 직업 인증/가치관 모달은 형제 요소인데 회원 UUID를 동일한 key로 사용했다. 각각 기능명+회원 ID로 구분해 중복 key 경고를 해소하면서 계정 변경 시 private 상태 초기화는 유지한다.
- 얼굴 화면의 `‹ 성장` 텍스트 버튼을 공통 48px 화살표 버튼+제목으로 통일했다. `replace`로 메인 탭을 새로 열지 않고 기존 화면으로 한 번만 back한다. 이전 화면이 없는 직접 진입은 `dismissTo`로 성장에 복귀한다. 접수 완료 버튼도 같은 동작을 사용한다.
- 목소리 화면 제목을 성장 카드와 같은 ‘목소리 정밀 학습’으로 맞췄다. 낭독 문장을 왼쪽 정렬하고 과한 여백/빈 자막창을 줄였다. 빈 자막창은 녹음 전에는 숨기며, 녹음 중/인식 결과가 있으면 표시한다.
- 읽을 문장·인식 결과를 화면의 남은 공간 중앙에 배치하고, 하단에 녹음 컨트롤 카드를 둔다. 상단으로 모든 내용이 몰려 하단이 비어 보이던 문제를 줄였다. 읽기 영역만 남은 높이를 사용하고 각 영역은 자연 높이를 유지하며, 둘을 한 스크롤에 넣어 긴 문장/큰 글자/가로 화면에서도 마지막 버튼까지 접근할 수 있다.
- 녹음 시각은 분:초로 표시한다. ‘끝내고 확인하기’와 시작 전 안내를 통해 문장을 확인한 후 조건에 맞는 음성만 전송한다는 점을 알린다. 접수와 학습 완료를 구분하는 기존 안내는 유지한다.
- 문장 조회 오류는 반복 팝업 대신 화면 안의 다시 불러오기 버튼으로 복구한다. 문장이 조회되지 않거나 조회에 실패한 경우 녹음 시작을 막는다. 마이크 권한이 없으면 기기 설정을 여는 선택지를 제공한다.
- 녹음 시작 시 문장 ID/본문을 보관하여 도중의 자동 refetch가 다른 문장으로 바뀌더라도 녹음한 원래 문장 ID로 전송한다. 초기화/전송 중 헤더 뒤로가기 버튼은 비활성화한다.

## 목소리 낭독 검증·대기 시간 개선 (2026-10-06)

- 실제 녹음 파일 URI와 최종 STT 결과가 모두 있어야 제출한다. 원문과 인식 결과를 Unicode NFKC·소문자로 정규화하고 공백/문장부호를 제외한 편집 거리로 비교한다. 기준은 75%이며 누락·다른 발화·과도한 추가 발화를 감점한다. 기준 미달이면 presigned URL 발급/파일 업로드/Job 등록 전에 차단하고 인식 결과·일치도·재녹음 안내를 남긴다. 문장을 타이핑해 통과시키는 입력은 없다.
- 일치도는 STT 문자의 유사도다. 발화자 신원·음질·의미/사실을 검증하지 않으며 숫자의 한글 발음이나 STT 오류로 정상 낭독도 재녹음이 필요할 수 있다. 서버에서도 강제하려면 AI가 원음과 sentenceId로 독립 검증해야 한다.
- 읽을 문장은 21px·중간 굵기·33px 줄 간격으로 정리하고 카드 최소 높이를 제거했다. 자막·안내·녹음 컨트롤 간격을 줄이며 시스템 글자 확대/자연 줄바꿈을 유지한다.
- 제출 성공 직후 로컬 접수 시각과 현재 회원의 기존 성장 캐시를 갱신해 서버 재조회 전에도 다음 녹음을 막는다. 제출 수와 학습 완료 여부는 추정해 변경하지 않는다. 다음 문장 버튼에 `01:59 후 가능`을 표시하고 2분 대기 중 비활성화하며, 시간이 지나면 활성화한다. 상태 조회 오류의 재확인 경로를 유지하고 앱 복귀 시 실제 시각으로 카운트다운을 갱신한다.
- 시간대 없는 lastVoiceTrainingAt은 앱의 한국 서비스 시간 기준으로 해석한다. 현재 백엔드는 LocalDateTime.now()를 사용하므로 배포 JVM 시간대 확인이 필요하다. 여러 국가/기기 시계 오차까지 지원하려면 serverNow와 nextVoiceTrainingAt을 UTC 또는 명시적 오프셋으로 제공하는 계약을 권한다. 백엔드·AI 코드는 변경하지 않았다.
- 이번 후속 변경 검증: 관련 6개 테스트 묶음·71개 테스트 통과, 수정 파일 ESLint 통과, tsc 기존 오류 30개/수정 파일 새 오류 0개, iOS·Android Metro/Hermes 번들 생성 통과. 실기기 음성 인식 품질과 실제 화면 배치는 별도 확인 대상이다.

### 하단 여백 후속 정리

- 스크롤 컨테이너는 화면 높이까지 확장하고, 읽기 영역은 flexGrow: 1/flexShrink: 0으로 남은 영역에서 중앙 정렬한다. 짧은 문장에서는 녹음 카드가 아래에 놓이고 긴 문장에서는 콘텐츠가 자연스럽게 늘어난다. 화면 높이/텍스트 길이로 고정 여백을 계산하거나 글자를 축소하지 않는다.
- 녹음 컨트롤은 마이크/종료 버튼과 상태 안내를 가로로 묶고 카드 테두리와 배경을 제공한다. 완료 시에는 접수 안내 아래에서 다음 문장·성장 복귀 버튼을 카드 전체 폭으로 제공한다. 일치도 검증·녹음 파일 필수 조건·2분 카운트다운 흐름은 유지한다.
- 이번 배치 변경 검증: 관련 2개 테스트 묶음·46개 테스트 통과, 수정 파일 ESLint 통과, 수정 파일 새 타입 오류 없음, diff 공백 검사 통과. 실제 Yoga 배치와 터치 사용감은 실기기 확인이 필요하다.

가치관 분석 메시지는 `jobId/userUuid/setNumber/previousSummary/answers`를 포함하고 내부 callback은 `personalitySummary`를 받는다. 현재 AI 체크아웃 전체에서 이 메시지의 소비/완료 callback 구현을 찾지 못했다. 별도 배포 서비스/워크플로가 있는지 AI 엔지니어 확인이 필요하며, 이 사실만으로 운영 배포에서도 미구현이라고 단정하지 않는다.

## 실기기 확인

1. 성장 진입: 서버 준비도/서류 제출 여부 로딩·조회 오류, 내 트윈 준비 전/후.
2. 직업 인증: 사진 선택/교체 취소/카메라 권한 거절/기기 설정 복귀/삭제/닫고 재진입. 선택한 사진이 접수됐다는 잘못된 표시가 없어야 한다.
3. 작은 iPhone/Android, 가로 화면, 큰 글자: 카드 제목·상태 문구, 서류 시트 마지막 버튼, 가치관 선택/닫기, 낭독/자막/종료 버튼.
4. 가치관: 질문 연속 탭, 실패 재시도, 8번째 답변 직후 휴식 상태, 12시간 후 다시 확인, 마지막 세트 답변 완료.
5. 목소리: 조용한 녹음/무음 오류/전송 오류, 제출 뒤 2분 쿨다운. 화면 성공은 녹음 접수이며 학습 완료라는 표시가 없어야 한다.
6. 얼굴 카드/직접 경로: 가입과 같은 얼굴·어깨 가이드, 정면/미소/말하기/좌우 촬영. 촬영 후 요청 버튼을 누르기 전 서버 전송이 없어야 한다. 접수 뒤 성장 복귀, 실패 재시도, 계정 변경, 기존 얼굴 유지/새 결과 반영은 실제 배포와 GPU 워커를 통해 확인한다.

컴포넌트 테스트·타입/lint·Metro/Hermes 번들 검증은 실제 Yoga 배치/네이티브 피커/권한/키보드/배포 서버 검증을 대체하지 않는다.

- iOS·Android Metro/Hermes 번들 생성 통과.
- `git diff --check` 통과. 실기기 촬영·권한·레이아웃과 배포 서버 연동은 직접 확인하지 않았다.
